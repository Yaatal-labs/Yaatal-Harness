🇬🇧 English

🟢 Stage — where it is now

An R&D project with a production-grade spine — two clocks in parallel:

  • Platform (live): Engine on Railway (auth/commerce/products verified end-to-end, private DB, seeded catalog, prod uuid-bug fixed); BOBO web on Cloudflare; full frontend → engine → Postgres round-trip proven.
  • Structure (formalized): two-repo split — Engine (runtime/control plane) + Harness (AI capabilities); alignment in progress.
  • Recently shipped: bilingual manifests (MD+HTML), inventory + SDK/BOBO slice plans, bilingual onboarding, and the @njooba→@yaatal rebrand (web-build verified).
  • Research (R&D): the sovereign Wolof model stack — not yet in production.

🔀 Pivots — the directional decisions

  • PowerSync → Engine HTTP — BOBO commerce off offline-sync; PowerSync now dead weight.
  • App backend → app-agnostic platform — the Engine is a product, not BOBO's backend.
  • Monolith → layered — capabilities split into the Harness; Engine = runtime/control plane.
  • NJOOBA → Yaatal — the seed isn't the umbrella; neutral shared scope.
  • Direct cloud AI → cascade + sovereignty — provider-agnostic, edge-first, compile-time residency.
  • Three backends → consolidate on Engine (in progress) — commerce on Engine; chat/delivery + payments flagged.
  • One app → multi-app platform — YOKK / BOBO / NJOOBA / DAARA, and a potential sovereign-AI product.
  • "Build it all" → two clocks — ship the platform now on cloud AI; let sovereign models graduate later.

🧠 Model choices — the AI stack & the "why"

Non-random design: the text seam (STT→text→MT→text→TTS) over opaque S2ST for auditability; real anchors + synthetic bridges + human review for low-resource data; the compounding Wolof commerce dataset as the durable moat. (All R&D except retrieval, partially real.)

🌍 Vision

A sovereign, edge-to-cloud AI platform for African (Wolof/French-first) commerce and assistance, whose core primitive is "models propose, the Engine disposes" — a sovereign AI-action control plane where on-device intelligence can suggest, but only a sovereignty-typed backend turns intent into money/orders/PII, with data compiled to never leave Senegal.
The moat

Sovereignty by construction · African-first AI economics · edge-aware retrieval · regional rails · a compounding low-resource-language data advantage.

The ceiling

The default sovereign AI backend for African builders — full-duplex Wolof voice-commerce on a cheap phone, on a weak network, data staying home.

The through-line: every pivot decouples the bet from the breakthrough — separating what can ship now from what research might unlock later. The vision is audacious because the architecture lets you pursue it without betting the company on the uncertain part.

🇫🇷 Français

🟢 Stade — où en est le projet

Un projet de R&D doté d'une colonne vertébrale de qualité production — deux horloges en parallèle :

  • Plateforme (en ligne) : Engine sur Railway (auth/commerce/produits vérifiés de bout en bout, DB privée, catalogue amorcé, bug uuid corrigé) ; BOBO web sur Cloudflare ; aller-retour frontend → engine → Postgres prouvé.
  • Structure (formalisée) : deux dépôts — Engine (runtime/plan de contrôle) + Harness (capacités IA) ; alignement en cours.
  • Livré récemment : manifestes bilingues (MD+HTML), plans inventaire + slice SDK/BOBO, onboarding bilingue, et le renommage @njooba→@yaatal (vérifié par le build web).
  • Recherche (R&D) : la pile de modèles wolof souverains — pas encore en production.

🔀 Pivots — les décisions directionnelles

  • PowerSync → HTTP Engine — le commerce BOBO quitte la synchro offline ; PowerSync = poids mort.
  • Backend d'app → plateforme agnostique — l'Engine est un produit, pas le backend de BOBO.
  • Monolithe → en couches — les capacités passent dans le Harness ; Engine = runtime/contrôle.
  • NJOOBA → Yaatal — la graine n'est pas l'ombrelle ; scope partagé neutre.
  • IA cloud directe → cascade + souveraineté — agnostique providers, edge-d'abord, résidence à la compilation.
  • Trois backends → consolider sur l'Engine (en cours) — commerce sur l'Engine ; chat/livraison + paiements à traiter.
  • Une app → plateforme multi-apps — YOKK / BOBO / NJOOBA / DAARA, et un produit IA souverain potentiel.
  • « Tout construire » → deux horloges — livrer la plateforme maintenant avec l'IA cloud ; modèles souverains plus tard.

(Tout en R&D sauf la recherche, partiellement réelle.)

🌍 Vision

Une plateforme d'IA souveraine, edge-vers-cloud, pour le commerce et l'assistance africains (wolof/français d'abord), dont la primitive est « les modèles proposent, l'Engine dispose » — un plan de contrôle d'actions-IA souverain où l'intelligence on-device peut suggérer, mais seul un backend typé-souveraineté transforme l'intention en argent/commandes/données, avec des données compilées pour ne jamais quitter le Sénégal.
Le fossé

Souveraineté par construction · économie IA africaine-d'abord · recherche consciente de l'edge · rails régionaux · un avantage de données en langue peu dotée qui se compose.

Le plafond

Le backend IA souverain par défaut des bâtisseurs africains — commerce vocal wolof full-duplex sur un téléphone bon marché, réseau faible, données au pays.

Le fil conducteur : chaque pivot découple le pari de la percée — séparant ce qui peut être livré maintenant de ce que la recherche pourrait débloquer plus tard. La vision est audacieuse parce que l'architecture permet de la poursuivre sans miser l'entreprise sur la partie incertaine.
